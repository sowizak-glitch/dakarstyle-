# Installation SeneCompare 5.2

Lien public : `https://senecompare.dakarstyle.com/?install=1&v=520`

- Android/Chrome, Samsung Internet, Edge et Brave : le bouton Installer utilise l’invite PWA native lorsqu’elle est disponible.
- iPhone/iPad : le même bouton affiche le guide Safari Partager → Sur l’écran d’accueil → Ajouter.
- Ordinateur : installation depuis Chrome ou Edge, ou utilisation directe dans le navigateur.

L’icône, le profil et le partage utilisent tous l’identité officielle SeneCompare Sénégal.
