# SeneCompare 5.2 — généralisation Sénégal

Cette couche est additive : elle conserve le moteur hybride, la confiance, les alertes, les signalements, les favoris, la comparaison, le partage et le secours vocal de la version 5.1.

## Parcours inclus

- produits grand public ;
- services du quotidien ;
- artisans ;
- transport et voyage ;
- santé et formation ;
- matériel agricole ;
- transport et manutention ;
- BTP, matériaux et outillage ;
- fournitures de bureau ;
- matériel de marchés et commerces ;
- matériel médical ;
- énergie, groupes électrogènes et solaire ;
- caméras et surveillance.

## Accessibilité terrain

- français et wolof ;
- pictogrammes compréhensibles ;
- mode grandes images ;
- commandes tactiles d’au moins 44 px ;
- navigation clavier ;
- animations réduites lorsque le téléphone le demande ;
- recherche par texte, toucher ou vocal ;
- installation Android et guide iPhone.

## Version

Interface : 5.2.0. Le moteur et les passerelles restent versionnés séparément afin d’éviter les régressions.
